# EMU800 型電聯車故障處理流程整理

> **用途**：供語音 AI 故障排除系統使用的人工整理版知識文件。
> **來源**：《EMU800 型電聯車故障處理手冊》（交通部臺灣鐵路管理局機務處，中華民國 107 年 11 月印）。
> **整理原則**：以原手冊為基礎，保留原有數值、設備名稱、操作位置與處置順序；為方便 AI 逐步詢問，將部分原本連續敘述改寫成「確認 → 判斷 → 處置 → 再確認」流程。
> **重要**：標示為「流程補充」的內容，是為了讓 AI 對話更完整而加入的流程控制語句（例如「若已恢復則結束本流程」），不是原手冊新增的技術處置。正式使用前應由熟悉 EMU800 的專業人員逐項確認。

---

## 0. AI 故障引導共通原則

### 0.1 對話開始時先確認

1. 已由 QR Code / 系統取得車型為 **EMU800**。
2. 請司機員說明主要故障現象。
3. 若現象仍不明確，優先詢問：
   - 是否已 Key ON？
   - 集電弓是否已升弓？
   - VCB 是否閉合？
   - TCMS-DDU 是否有故障指示？
   - 故障發生於啟動時或行駛中？
   - 是否為單一車、單一組或全列車？
4. 依回答進入下列對應流程。

### 0.2 AI 執行原則

- 每次原則上只詢問或指示 **一個可確認事項**。
- 已確認的狀態不要重複詢問。
- 數值型資訊應要求司機員回報實際值，再由系統判斷門檻。
- 涉及「強迫激磁、隔離、轉供、降弓、Key OFF、考克操作」時，不要自行省略前置條件。
- 原手冊寫有「上述處理無效」時，AI 必須確認前一處置確實無效後，才能進入後續步驟。
- 若某一步處置後故障已恢復，**流程補充：停止繼續執行後續處置，回報故障已恢復。**
- 若資料不足以判斷，不自行創造處置方式。

# 第一章 動力系統

## 1. 起動迴路無法建立

### 故障現象

- Key ON 後，110V 電瓶電壓無法建立。

### 故障處理流程

1. **確認兩輛 ED 車「總控制」開關**
   - 位置：ED 車電氣室內主配電盤。
   - 確認是否位於 **ON**。
   - 若不是 ON → 扳至 ON 後重新確認是否可建立 110V。
   - 若正常但仍無法建立 → 下一步。

2. **確認本務車控制開關**
   - 位置：駕駛室司機側後方主配電盤。
   - 確認「本務車控制」是否位於 **ON**。
   - 若不是 ON → 扳至 ON 後重新確認。
   - 若正常但仍無效 → 下一步。

3. **反覆 Key ON / Key OFF**
   - 嘗試數次。
   - 若恢復 → 結束。
   - 若無效 → 下一步。

4. **強迫 HCR1～HCR4 繼電器**
   - 嘗試將 HCR1～HCR4 繼電器強迫激磁。
   - 若恢復 → 結束。
   - 若無效 → 下一步。

5. **換端重新啟動**
   - 換端後重複嘗試啟動。

> 來源：手冊第 3～4 頁。

## 2. 輔助風泵不作用

### 故障現象

- Key ON 後輔助風泵不運轉。
- 因輔助風壓不足，集電弓無法升弓。

### 故障處理流程

1. **確認 DC110V 供電**
   - ED 車客室開關盤：
     - 「蓄電池接觸器」開關應在 **ON**。
     - 「蓄電池(110V)(BatN2)」開關應在 **ON**。
   - 若異常 → 恢復至 ON，確認 DC110V 是否正常。
   - 若正常仍不作用 → 下一步。

2. **確認 EP 車「輔助風泵」無熔絲開關**
   - 位置：EP 車電氣室。
   - 應位於 **ON**。
   - 若跳開 / OFF → 恢復至 ON 後確認輔助風泵。
   - 若正常仍不作用 → 下一步。

3. **輕敲 ACMG**
   - 前述開關皆正常時，嘗試輕敲 **ACMG（輔助風泵壓力開關）**。
   - 確認輔助風泵是否恢復運轉。
   - 若無效 → 下一步。

4. **以緊急考克使 ACMG 強迫閉合**
   - 將輔助風泵裝置內緊急考克扳至 **隔離位**，使 ACMG 強迫閉合。
   - 確認輔助風泵是否運轉。
   - **重要復位條件**：待升弓、VCB 閉合、MR 壓力達 **7 bar** 後，須將考克復位。
   - 若仍無效 → 下一步。

5. **強迫 ACMK 激磁**
   - 上述處理皆無效時，將 **ACMK 強迫激磁**，令輔助風泵運轉。
   - **勿強迫太久**。
   - 壓力達 **5.5 bar** 即足以供升弓使用。

> 來源：手冊第 4～7 頁。
> 流程補充：步驟 4 使用緊急考克後，AI 應記錄「考克待復位」狀態，於升弓、VCB 閉合及 MR ≥ 7 bar 後主動提醒復位。

## 3. 集電弓無法升弓

### 進入本流程的條件

- Key ON。
- 輔助風缸壓力約達 **5 bar**。
- 控制電源達 **80V 以上**。
- 按下升弓按鈕後無動作。

### 故障處理流程

1. **確認「主控制器」無熔絲開關**
   - 位置：駕駛室司機側主配電盤。
   - 應位於 **ON**。
   - 若不是 ON → 恢復後再試升弓。
   - 若正常仍無法升弓 → 下一步。

2. **確認按鈕是否固著**
   - 多按數次：
     - 降弓按鈕。
     - VCB 切開按鈕。
   - 確認是否有按鈕固著。
   - 再試升弓。
   - 若仍無效 → 下一步。

3. **確認 ZVR / HCR2**
   - 檢查駕駛室司機側主配電盤之 **ZVR 或 HCR2** 是否至少其中之一有激磁。
   - 若兩者皆無激磁 → 嘗試強迫其中之一激磁，再按升弓。
   - 若仍無法升弓 → 下一步。

4. **確認 PUR**
   - 在上述繼電器與開關正常下仍無法升弓：
   - 檢查 **PUR 繼電器**是否激磁。
   - 若無 → 強迫激磁，再確認能否升弓。
   - 若無效 → 下一步。

5. **確認「集電弓電磁閥」無熔絲開關**
   - 位置：EP 車電氣室。
   - 應位於 **ON**。
   - 若不是 ON → 恢復後再試。
   - 若正常仍無效 → 下一步。

6. **確認升弓電磁閥電源線**
   - 位置：EP 車電氣室。
   - 確認升弓電磁閥兩條電源線是否接妥。
   - 若異常 → 處理後再試。
   - 若正常 → 下一步。

7. **確認 VCB 下方接地開關**
   - 接地開關應位於 **正常位**。
   - 若在 **接地位** → 無法升弓。
   - 恢復正常位後再試升弓。
   - 若正常仍無效 → 下一步。

8. **確認集電弓氣源壓力**
   - 位置：EP 車電氣室外側集電弓氣源壓力錶。
   - 應達 **5.5 bar 以上**。
   - 若 ≥ 5.5 bar → 流程補充：氣源條件可視為成立，若仍無法升弓則進入步驟 9。
   - 若 < 5.5 bar：
     1. 檢查 EP 車外、輔助風泵上方「集電弓緊急隔離考克」是否在正常 / 開通位。
     2. 檢查 EP 車電氣室「升降弓切斷考克」是否在正常 / 開通位。
     3. 恢復後再確認壓力與升弓。

9. **換端與 SIV 轉供**
   - 上述處理均無效時，換端啟動。
   - 若另一組可正常升弓，且 SIV1、SIV2 正常：
     1. 全列車降弓，Key OFF。
        - 原手冊註記：沒降弓，Key OFF 也可以做以下步驟。
     2. 故障組 EMB 車客室配電盤：SIVCOS → **隔離位**。
     3. 正常組 EMB 車客室配電盤：SIVCOS → **轉供位**。
     4. 升弓。
     5. SIV 自動轉供後繼續行駛。
   - SIV 轉供完成時，兩端 EMB 車紅色燈亮。

> 來源：手冊第 8～12 頁。

## 4. 升弓後 VCB 不閉合（TCMS-DDU 無其他故障指示）

### 進入本流程的條件

- TCMS-DDU 顯示 EP 車集電弓已升弓。
- 升弓後 **20 秒內 VCB 未閉合**。

### 故障處理流程

#### A. 先確認電車線電壓

1. **詢問 / 讀取電車線電壓**
   - 正常範圍：**19.0 kV ～ 27.5 kV**。
   - 若 `< 19.0 kV` 或 `> 27.5 kV`：
     - 以行調無線通知相關單位處理。
     - **停止一般車上 VCB 排除流程，先處理外部供電條件。**
   - 若在範圍內 → 下一判斷。

2. **特殊分支：一車 VCB 閉合、另一車未閉合且故障組無電車線電壓指示**
   - 可能為 **HVT 保險絲燒損**。
   - 將正常車 SIV 電源轉供至故障組。
   - 繼續運轉。
   - 此分支完成後可結束本流程。

#### B. 確認 VCBOTR

3. **檢查 VCBOTR 繼電器**
   - 位置：駕駛室司機側主配電盤。
   - 判斷方式：繼電器下方兩指示燈是否點亮。
   - 若未激磁：
     1. 嘗試輕敲。
     2. 或斷電後拔開重插。
     3. 再升弓。
   - 若 VCB 已恢復閉合 → 結束。
   - 若仍無法閉合 → 下一步。

#### C. 確認 VCBAR

4. **檢查 TCMS-DDU 的 VCBAR**
   - 位置：TCMS-DDU 主畫面右上方。
   - 確認本務車 VCBAR 是否有閉合指示 / 反白（圖示說明為反綠）。
   - 車號位置：
     - 2：單號車 EMA
     - 4：單號車 EMB
     - 5：雙號車 EMB
     - 7：雙號車 EMA

5. **若 VCBAR 無閉合**
   1. EMA / EMB 客室配電盤「牽引電源 1 / 2」關閉後重開。
   2. 再確認 VCBAR / VCB 是否閉合。
   3. 若仍無閉合 → EMA / EMB 客室配電盤「主變流器隔離開關」扳至 **1 位**。
   4. 再確認。
   5. 若仍無效 → 下一步。

6. **TCU 轉換**
   - 駕駛室司機側主配電盤「TCU 轉換開關（CCOS）」切至 **1 位**。
   - 等待並觀察 VCB 是否可以閉合。
   - 若恢復 → 結束。
   - 若仍無效，且後連組可閉合 VCB：
     - 正常組 SIV 轉供後繼續行駛。
   - 若不符合轉供條件或需繼續排除 → 下一步。

#### D. EP 車電氣室檢查

7. **VCB 控制無熔絲開關**
   - 應位於 **ON**。
   - 若不是 ON → 扳至 ON，重新確認 VCB。

8. **VCBCR1 / VCBCR2**
   - 確認是否有閉合 / 激磁。
   - 若無 → 嘗試強迫激磁。
   - 再確認 VCB。

9. **APCTR**
   - 在 **VCBOTR 未激磁狀態**下確認 APCTR 是否激磁。
   - 圖示補充：激磁時繼電器指示燈應亮。
   - 若無激磁：
     - 原圖示說明提供：嘗試輕敲 APCTR，或降弓後拔開繼電器重插。
   - 再確認 VCB。

10. **主變壓器油泵無熔絲開關**
    - 位置：EP 車電氣室。
    - 應位於 **ON**。
    - 若不是 ON → 扳至 ON。

11. **SeOCR1 / SeOCR2 與 SeOCN1 / SeOCN2**
    - 確認 SeOCR1、SeOCR2 是否激磁。
    - 若無：
      1. 至車下「SIV 保險絲及二次側比流器箱」。
      2. 確認 SeOCN1、SeOCN2 無熔絲開關是否位於 **ON**。
      3. 若不是 ON → 扳至 ON。
    - 再確認 SeOCR1 / SeOCR2。
    - 若仍無激磁 → 強迫 SeOCR1 / SeOCR2 激磁。
    - `SeOCR1/2`：二次側過電流繼電器。

12. **ACOCRR**
    - 確認 EP 車電氣室 ACOCRR 繼電器是否激磁。
    - 若無 → 強迫激磁。
    - `ACOCR`：AC 過電流繼電器。
    - `ACOCRR`：ACOCR 繼電器。

#### E. 最後確認與降級處置

13. **換端 + VCB 限壓閥壓力**
    - 上述狀況皆正常但 VCB 仍無法閉合：
      1. 換端啟動嘗試。
      2. 檢查 VCB 限壓閥壓力錶。
    - VCB 閉合所需壓力：**4.5 bar 以上**。
    - 若低於 4.5 bar，但後連組正常運作：
      - 待壓力達標後再確認，達標後可正常閉合。

14. **最終 SIV 轉供**
    - 上述處理均無效。
    - 若後連組可升弓且 VCB 可閉合：
      - 將正常組 SIV 電源轉供。
      - 繼續行駛。

> 來源：手冊第 13～20 頁。
> 流程補充：此流程中有多個「處置後重試」點。AI 應在每次操作後先問「VCB 是否已閉合？」；已恢復就停止，不應繼續執行後續隔離或強迫操作。

## 5. 行駛中 VCB 切開 / 不閉合，TCMS-DDU 合併其他故障指示

### 進入本流程的條件

- 列車行駛中。
- TCMS-DDU 有故障指示，並伴隨 VCB 切開。

### 依 TCMS-DDU 故障名稱直接分流

| 故障指示 | 處理 |
|---|---|
| 一次側過電流 | 降弓後重新升弓 |
| 主變壓器油流微動開關跳脫 | 待微動開關自動復位後，降弓再升弓 |
| 主變壓器油流停止 | 檢查 EP 車油流開關是否在 ON；若有，降弓後重新升弓 |
| VCB 控制壓力低壓 | 待壓力充足後，降弓再重新升弓 |
| 旁路接觸器切開 | 降弓後重新升弓 |
| 接地故障電流 | 電門收 OFF，自動復位 |
| 主變壓器直流成分過高 | 電門收 OFF，自動復位 |
| 二次側短路 | 降弓後重新升弓 |
| 二次側過載 | 電門收 OFF；若無效，隔離故障車之馬達及牽引變流器 |
| 電車線過電壓 | 電門收 OFF，待電車線電壓正常後自動復位 |
| 電車線低電壓 | 電門收 OFF，待電車線電壓正常後自動復位 |
| 動力電路再接地 | 電門收 OFF |
| 牽引變流器整流失敗 | 電門收 OFF，隔離故障車之馬達及牽引變流器 |
| 牽引馬達過載 | 電門收 OFF |

> 來源：手冊第 20～21 頁。
> 流程補充：AI 應先要求使用者念出 / 確認 TCMS-DDU 的故障名稱，再匹配本表，不應僅依「VCB 切開」猜測原因。

## 6. 不出力，TCMS-DDU 無故障指示

### 進入本流程的條件

- 集電弓已升弓。
- VCB 已閉合。
- 拉電門無法出力。
- TCMS-DDU 無故障指示。

### 故障處理流程

1. **司軔閥**
   - 確認司軔閥把手是否在 **運轉位**。
   - 若不是 → 恢復至運轉位後再試出力。

2. **車門條件**
   - 看車門燈是否亮。
   - 由 TCMS-DDU 確認全列車車門是否關閉。
   - 若 TCMS 顯示車門已關閉，但仍因車門連鎖無法出力：
     - 將駕駛室助理側後方配電盤「DIRS」轉至 **旁路位**嘗試。
   - 若旁路後可出力：
     - 檢查車門未關側車下「上下台門隔離考克」是否位於隔離位。

3. **TCOR**
   - 檢查駕駛室助理側後方 ATP 配電盤內 **TCOR 繼電器**是否作用。
   - 原手冊註：ATP 在隔離位時，該繼電器左側小燈不會亮。

4. **停留軔機條件**
   - 檢查駕駛桌面「泊車燈」是否亮。
   - 檢查 TCMS 主畫面停留軔機指示方塊。
   - 檢查車側綠色停留軔機燈是否熄滅。
   - 若停留軔機仍作用 → 轉入「停留軔機不鬆軔」流程。

5. **MR / BP 壓力**
   - MR 壓力應達 **7.5 bar 以上**。
   - BP 壓力應達 **4 bar 以上**。
   - 若未達標 → 流程補充：先處理壓力不足，不應直接進入後續出力電路處置。
   - 若均達標仍不出力 → 下一步。

6. **速控 / 牽引力控制**
   - 試將緊急開關之「速控位」轉至「牽引力」，嘗試出力。
   - 圖示文字亦描述可在速控與牽引力控制間切換後再試。
   - 若無效 → 下一步。

7. **牽引電源 1 / 2 復位**
   - EMA / EMB 客室配電盤：
     - 「牽引電源 1」
     - 「牽引電源 2」
   - 關閉後重新復位，再試出力。
   - 若無效 → 下一步。

8. **TCU 轉換**
   - 駕駛室司機側後方主配電盤「TCU 轉換開關」→ **1 位**。
   - 再嘗試出力。

## 7. 不出力，TCMS-DDU 有故障指示

### 進入本流程的條件

- 列車無法出力。
- TCMS-DDU 有明確故障訊息。

### 依故障訊息分流

| TCMS-DDU 故障指示 | 故障處理流程 |
|---|---|
| 主變壓器油泵故障 | 電門收 OFF → 至 EP 車電氣室檢查主變壓器油泵開關 |

| 二次側過電流 | 自動復位，不需動作 |

| 馬達速度脈衝探針故障（全列車） | 電門收 OFF → 降弓後重新升弓 |
| TCU 監視計時器故障 | 電門收 OFF → 自動復位 |
| 110V 電瓶低電壓 | 電門收 OFF → 檢查 EP 車客室配電盤總控制及 Batk2 電瓶開關是否跳脫 → 仍無效時盡速求援 |
| TCU 控制電源低電壓 | 電門收 OFF → 若無效，TCU 轉換開關切至 1 位後繼續行駛；或隔離故障馬達車之 TCU 後繼續行駛 |
| 電軔失效 | 電門收 OFF → 自動復位 |

| DC-L 預充電故障 | 電門收 OFF → 再拉至出力段位；若無效，隔離故障牽引變流器後繼續行駛 |
| 放電接觸器未開啟 | 電門收 OFF → 再拉至出力段位；若無效，隔離故障牽引變流器後繼續行駛 |
| Conv-U 相模組溫度過高 / Inv 模組溫度過高 | 電門收 OFF → 待溫度下降後自動復位行駛；必要時可隔離相關牽引變流器後繼續行駛 |
| PWM 信號異常 | 電門收 OFF → 若無法自動復位，TCU 轉換開關切至 1 位，嘗試出力行駛 → 若無效，盡速請求救援 |
| 所有 TCU 都在被控位 | 電門收 OFF → 若無法自動復位，TCU 轉換開關切至 1 位，嘗試出力行駛 → 若無效，盡速請求救援 |

# 第二章 SIV 系統

## 8. SIV 無法啟動

### 故障處理流程

1. **先確認 VCB**
   - TCMS-DDU 顯示 VCB 是否已閉合。
   - 若 VCB 未閉合 → 流程補充：優先轉入 VCB 不閉合流程。
   - 若 VCB 已閉合 → 下一步。

2. **SIV 總電源**
   - EMB 車配電盤「SIV 總電源」斷流器應在 **ON**。

3. **SIV1 / SIV2 控制電源**
   - EMA 車客室配電盤：「SIV1 電源」應在 **ON**。
   - EMB 車客室配電盤：「SIV2 電源」應在 **ON**。

4. **SIVCOS**
   - 確認 SIVCOS 開關位於 **正常位**。

5. **重新啟動**
   - 若上述均正常但 SIV 仍無法啟動：
     1. 降弓。
     2. Key OFF。
     3. 等待 **6 秒**。
     4. 重新升弓。

> 來源：手冊第 29～31 頁。

## 9. 組內 SIV1 或 SIV2 單一故障

1. 正常情況下，同組另一台 SIV 會 **自動轉供**。

# 第三章 軔機系統

## 13. 全列車不鬆軔：BC 2.7～3.0 bar、BV 7 段

### 症狀辨識

- 司軔閥把手在運轉位。
- ED 車 BC（軔缸）壓力保持 **2.7～3.0 bar**。
- TCMS-DDU 主畫面 BV 段位為 **7 段**。
- 無明顯排氣聲。
- 全列車無法鬆軔。

### 處理

1. 檢查 **後端駕駛室 ATP 隔離開關是否未關閉**。
2. 流程補充：
   - 若 ATP 狀態異常 → 依規定恢復正確狀態後，再確認 BC 是否下降、列車是否鬆軔。
   - 若症狀不符合本型態 → 回到「不鬆軔症狀分類」重新判定。

> 來源：手冊第 34～35 頁。

## 14. 全列車不鬆軔：BC 3.4 bar、BP 0 bar、BV=EB

### 症狀辨識

- ATP 無緊急緊軔作動下。
- 司軔閥把手在運轉位。
- BC 約 **3.4 bar**。
- BP 約 **0 bar**。
- 有明顯排氣聲。
- TCMS-DDU 的 BV 顯示 **EB（緊急緊軔）**。

### 處理

1. 檢查駕駛室助理側後方 ATP 配電盤：
   - EB 繼電器。
   - RB 繼電器。
2. 若繼電器有動作（指示燈亮）：
   - 嘗試輕敲。
3. 若上述處理無效：
   - 將 ATP 重新開機。
4. 重新確認：
   - BP 是否恢復。
   - BC 是否下降。
   - BV 是否離開 EB。

> 來源：手冊第 35～37 頁。

## 16. 單一車廂無法鬆軔

### 症狀

- 其他車廂皆已鬆軔。
- 僅單一車廂顯示不鬆軔。

### 故障處理流程

1. **司軔閥反覆操作**
   - 鬆軔位 → 七段 → 鬆軔位，反覆數次。
   - 若恢復 → 結束。

2. **CR 風缸排氣復位**
   - 若步驟 1 無效：
     1. 司軔把手置運轉位。
     2. 到不鬆軔車廂車下 BOU 單元。
     3. 將「CR 風缸」拉桿拉到底。
     4. 將空氣排盡。
     5. 拉桿推回定位。
     6. 重新鬆軔－緊軔一次。
   - 確認是否恢復。

3. **改用自動軔機**
   - 若仍無效：
     - 駕駛室司機側後方主配電盤「軔機控制 1」→ **OFF**。
     - 改以自動軔機操作。
     - 確認是否可以鬆軔。

4. **隔離故障轉向架軔缸**
   - 上述均無效：
     - 將無法鬆軔之轉向架車下軔缸考克隔離。
     - 繼續行駛。

> 來源：手冊第 38～40 頁。
> 注意：原手冊圖示另顯示 BOU 氣源切斷、前 / 後轉向架軔缸開關隔離位置；實際選擇何一隔離方式，應由專業人員依現場狀況與既有規定確認。

## 19. 全列車停留軔機無法鬆軔

### 症狀

- 按下停留軔機按鈕後，全列車停留軔機無法鬆軔。

### 故障處理流程

1. **總風缸壓力**
   - 確認總風缸壓力是否達 **7 bar 以上**。
   - 未達 7 bar → 停留軔機尚不具鬆軔條件。
   - 達 7 bar 仍不能鬆軔 → 進一步確認實際停留軔機狀態。

2. **TCMS 已確認全列車實際鬆軔，但泊車燈不熄**
   - 前提：
     - TCMS-DDU 顯示全列車停留軔機壓力已無。
     - 必須再三確認全列車停留軔機確實已鬆軔。
     - 泊車燈仍不熄、因此無法出力。
   - 處理：
     - 強迫駕駛室司機側主配電盤 **PAR 繼電器**激磁。
   - 泊車燈熄滅後可出力。

> 來源：手冊第 43 頁。
> **安全重點**：PAR 強迫激磁前，原手冊明確要求「再三確認全列車停留軔機已鬆軔完成」。

## 20. 單車停留軔機不鬆軔

### 故障處理流程

1. **MR 壓力**
   - 確認故障車 MR 壓力是否達 **7 bar 以上**。
   - 若未達 → 流程補充：先處理壓力條件。
   - 若達 7 bar 以上 → 下一步。

2. **停留軔機壓力開關**
   - 打開車下停留軔機控制箱。
   - 嘗試輕敲「停留軔機壓力開關」。
   - 再確認是否鬆軔、車側停留軔機燈是否熄滅。

3. **PBPSR**
   - 若上述完成後車側停留軔機燈仍不熄：
     - 至車上電氣室確認 **PBPSR** 是否激磁。
   - **前提：車下已確認停留軔機確實已鬆軔。**
   - 若已實際鬆軔但 PBPSR 未正確反映：
     - 強迫 PBPSR 激磁。
     - 車側停留軔機燈可熄滅，列車可出力。

4. **手動鬆軔**
   - 若仍無效：
     1. 至客室雙針壓力計旁，將「停留軔機隔離考克」扳至隔離。
     2. 至車下操作：
        - 左三（#5 位）
        - 右四（#8 位）
       停留軔機手動拉環，使停留軔機手動鬆軔。
     3. 確認實際已鬆軔。
     4. 將故障車 PBPSR 強迫激磁。
     5. 車側綠色停留軔機燈熄滅。
     6. PAR 激磁後列車可出力。

> 來源：手冊第 43～45 頁。
> 流程補充：手冊 2-2-3 與 2-2-4 內容高度相近，本整理將其合併成「隔離 → 手動鬆軔 → 實際確認 → PBPSR → 出力」的單一路徑，避免 AI 重複要求同一動作；正式使用前請人工確認此合併是否符合現場作業習慣。

## 22. 主風泵不運轉，總風缸壓力不足

### 進入本流程的條件

- VCB 已閉合。
- SIV 輸出正常。

     - 打開「壓縮機啟動裝置箱」，嘗試輕敲「主風泵壓力開關（CMG）」。

4. **CMGR**
   - 嘗試輕敲 **CMGR 繼電器**。

> 來源：手冊第 46～50 頁。
> 人工覆核提示：原手冊 4-1-2 與 4-1-3 均包含輕敲 CMG 的動作，可能是刻意重試，也可能是編排重複。AI 正式流程應由專業人員決定是否合併。

## 24. DC110V 充電故障

   - 將「蓄電池充電器(110V)（TBCN）」斷流開關關閉後重新復位。
3. 確認充電是否恢復。
4. 若充電器復位無效，且合併 **110V 電瓶低電壓**：
   - **盡速請求救援**。

> 來源：手冊第 52～53 頁。

# 第五章 DC24V 系統故障

## 25. DC24V 電瓶不放電

### 故障處理流程

1. **24V 蓄電池開關**
   - 故障車：
     - 24V 蓄電池（BatK2N）開關應位於 **ON**。
     - 蓄電池開關（BN）應位於 **ON**。

2. **BatK2 / BatK3**
   - 確認電瓶接觸器 **BatK2、BatK3** 是否激磁。
   - 若無 → 嘗試強迫激磁。

3. **仍為 24V 低電壓：節電與降級運轉**
   - 若上述處理無效：
     1. 將故障車電燈關閉。
     2. 僅留緊急燈，以節省電力供車門開關使用。
     3. 駕駛室助理側後方配電盤「車門連鎖繼電器」切至 **旁路位**。
     4. 繼續行駛。
   - 若故障電瓶位於 EMC 車：
     - 頭燈電源由 **24V** 切換為 **110V** 供應。
     - 繼續行駛。

> 來源：手冊第 53～55 頁。

---

## 26. DC24V 充電系統故障

1. 至故障車主配電盤：
   - 將「蓄電池充電器(24V)」斷流開關關閉後復位。
2. 確認充電是否恢復。
3. 若復位無效且電瓶輸出低電壓：
   - 依「DC24V 電瓶不放電」步驟 3 的節電與降級運轉方式處理。

> 來源：手冊第 56 頁。

# 人工覆核清單

以下項目建議在轉成正式 YAML / Decision Graph 前由專業人員確認：

1. **輔助風泵不作用**：原手冊第 4～5 頁「蓄電池接觸器 / BatN2」檢查內容有重複編號，正式流程是否只需一次。
2. **VCB 不閉合**：VCBAR「反白」與圖片說明「反綠」的用語應統一成現場司機員最熟悉的描述。
3. **VCB 不閉合 APCTR**：正文只寫「檢查 APCTR 是否激磁」，圖片說明另包含「輕敲 / 降弓拔開重插」；正式資料庫是否將圖片說明視為正式操作步驟。
